
## 키친로그 (Kitchen Log)

> 식재료 관리 애플리케이션 <br/>
> 식재료를 편리하게 관리하고 레시피를 추천받자!

<br/>

## 개발 기간
2025.12 ~ 2026.01

<br/>

## 기술 스택
- Java 21
- Spring Boot 4.0
- MySQL 8.0.44
- NCP(Naver Cloud Platform), GCP(Google Cloud Platform)
- Docker
- NGINX
- Prometheus, Grafana, Loki, Discord(Server Metric Alert)
- Naver Clova Studio(LLM)
